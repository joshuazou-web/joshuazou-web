# 《中国噜会飞》抖音短视频方案

> 一句话：让全网最躺平的橘色水豚，踩着「中国人会飞」的鼓点飞起来。反差就是爆点。
>
> **为什么叫「中国噜会飞」**：跟原句「中国人会飞」一样是五个字，只把「人」换成「噜」。节奏不变，**能直接跟着原曲唱**，一眼就认得出是这个梗，又好念、好打成话题。

## 0. 素材是什么

| 素材 | 事实 | 对我们的意义 |
|---|---|---|
| **水豚噜噜** | 头顶橘子的小水豚，人设是呆萌、情绪稳定、爱泡澡、爱放假。版权方：铁罐（北京）文化传媒。全网播放 17 亿+，表情包下载 6000 万+ | 有现成的认知度，而且人设就是“最不可能飞的那个” |
| **「中国人会飞」梗** | 揽佬 & 真龙的歌《中国人能飞》（“中国人会飞，黄皮肤才对”）。2026-08-15 曹骏在《披荆斩棘 2026》舞台上耍枪空翻，把梗做成了画面；《国防时报》转发后被当成“正能量”，二创一路做到太空行走、高铁、大飞机试飞 | 这首 BGM 有现成流量，二创模板也被验证过 |
| **组合** | 橘黄色的水豚配“黄皮肤才对”，躺平的水豚配“会飞” | 颜色上对得上，性格上又是反差，两层梗叠在一起 |

## 1. 为什么（看起来）还没人做

我没法直接搜抖音站内，所以不敢说“完全没人做”。不过没人做好，大概有这几个原因：

1. **梗还新**：8 月中旬才爆，大家都在拿真人、大国重器二创，还没轮到萌宠 IP。
2. **版权门槛**：噜噜是有主的 IP，个人号直接用它的形象做内容，可能被投诉下架，所以普通创作者不敢碰；官方号的反应又慢。
3. **做起来有成本**：要让噜噜“飞”就得做动画。以前一条要几天，现在 AI 图生视频半天就能出。
4. **人设看起来冲突**：大家觉得“躺平水豚”跟“燃”不搭。**其实这正是卖点。**

## 2. 核心创意：先躺后飞

- **前 2 秒（钩子）**：噜噜泡在澡盆里，头顶橘子，一脸“别叫我”。字幕：**「都说中国人会飞，那我呢？」**
- **鼓点一落**：橘子弹起来，噜噜跟着飞出澡盆。
- **高潮**：噜噜飞过长城、高铁、天宫空间站（跟这首歌的主流二创画面接上），**全程面无表情**。
- **结尾反转**：飞一圈落回澡盆，“噗通”一声，橘子落回头顶，字幕：**「飞完了，泡澡。」**

表情稳定、动作离谱、最后回到原点，这三点就是它的笑点和记忆点。

## 3. 分镜脚本（约 18 秒，卡原曲副歌）

| 时间 | 画面 | 声音/字幕 |
|---|---|---|
| 0–2s | 俯拍：噜噜泡澡，橘子在头顶，冒热气 | 环境音“咕嘟”；字幕「都说中国人会飞」 |
| 2–3s | 特写：噜噜缓缓睁开一只眼 | 字幕「那我呢？」；BGM 起 |
| 3–5s | 橘子弹起来，噜噜“嗖”地跟着飞出，水花四溅 | 副歌第一句「中国人会飞」，字幕做成「中国~~人~~**噜**会飞」：「人」打叉，换成「噜」 |
| 5–8s | 噜噜平躺着飞过长城，姿势跟泡澡时一样 | 「黄皮肤才对」，字幕加一句「橘皮肤也对」 |
| 8–11s | 跟高铁并排飞，窗里的乘客举手机拍它 | BGM |
| 11–14s | 飞出大气层，在空间站窗外跟航天员对视 | BGM 高潮 |
| 14–16s | 急速下坠，划出一道橘色流星 | 音效“咻——” |
| 16–18s | 落回澡盆，橘子稳稳落回头顶，闭眼 | 字幕「飞完了，泡澡。」+ 定格 |

**封面**：噜噜平躺飞在长城上空，大字写「中国噜会飞」。

## 4. 三个版本，按版权风险选

| 版本 | 做法 | 风险 | 建议 |
|---|---|---|---|
| **A 官方授权版** | 联系铁罐文化，拿授权或者直接合作发 | 最低 | **想放大流量、带货，只能走这个** |
| **B 原创橘色水豚** | 自己设计一只头顶柿子/金桔的水豚，名字另取，比如「豚飞飞」 | 低 | 个人号马上能做，以后还能养成自己的 IP |
| **C 真人 + 玩偶** | 用正版噜噜玩偶实拍，拿威亚或手举着“飞”，走土味手工路线 | 中（非商用二创一般能容忍） | 成本最低，土味反而贴这首歌的调性 |

## 5. 制作流程（AI 图生视频，大约半天）

1. **定角色**：先出 3–5 张同一角色不同角度的图，锁住形象，避免每个镜头长得不一样。
2. **逐镜生成**：用图生视频工具（可灵、即梦等）每个镜头出 3–5 秒，每镜多抽几次挑最好的。
3. **剪辑卡点**：剪映里导入抖音音乐库的原曲，镜头切换全都卡在鼓点上。
4. **字幕**：白字黑描边，大字只放在钩子和结尾两处，中间不加字，让画面自己说话。
5. **标识**：发布时勾选「作品含 AI 生成内容」，这是平台规定，不勾会被限流。

## 6. 发布打法

- **标题**：`中国噜会飞 🍊 #中国噜会飞 #中国人会飞 #中国人能飞 #卡皮巴拉 #水豚噜噜 #情绪稳定`
- **BGM**：必须用抖音音乐库里的原曲，别自己上传，这样才能进这首歌的聚合页，吃到它的流量池。
- **时间**：工作日 12:00–13:00 或 18:00–22:00。
- **评论区**：自己先置顶一条「下一期让噜噜飞去哪？」，把互动带起来。
- **系列化**：第一条数据好的话，按评论点名做第 2、3 期，比如「噜噜飞去西藏」「噜噜飞去奥运会」，也可以开放合拍，让别人家的宠物一起“会飞”。
- **时效**：梗的热度一般撑 4–8 周，**这周就发**，晚了就只能跟风。

## 7. 红线

- 不搬运曹骏的舞台原片，也不搬运别人的二创，只借梗和 BGM。
- 国旗、军人、领导人形象一律不放。宁可用长城、高铁、空间站这类公共符号，也别碰敏感元素。
- 版本 A 以外，不拿噜噜形象挂车带货。
- 不买量、不刷数据，刷了会被判异常，反而限流。

## 8. 怎么判断能不能火（发布后 2 小时看）

| 指标 | 及格线 | 说明 |
|---|---|---|
| 5 秒完播率 | > 50% | 不到就是钩子不够，换开头重发 |
| 整体完播率 | > 30% | 18 秒的片子要做到这个数 |
| 点赞/播放 | > 5% | 过了会被推进更大的流量池 |
| 评论/播放 | > 0.5% | “下一期飞去哪”这类互动是续命关键 |

> 老实说：没人能保证一条视频一定爆。能做的是把钩子、卡点、反差和时效这四件事做到位，再用第 8 节的数据快速迭代：第一条不行就换钩子，当天再发。
