## 粉丝体验调研问卷（可做成后续的私信 / 粉丝群问卷）

图 16 的评论区投票只问了一题，想做更完整的用户调研可以用下面这份，回收后能直接做下一期「简单科技粉丝怎么看 AI 代理人」。

1. 你现在用 AI 工具的频率？ 每天 / 每周几次 / 偶尔 / 几乎不用
2. 你用过下面哪类产品？（多选）聊天类（豆包、Kimi、ChatGPT 等）/ AI 搜索 / AI 写作或做图 / 能自己执行任务的智能体 / 都没用过
3. 如果有一个 AI 代理人，你最想先交给它哪件事？ 订餐订票 / 回消息邮件 / 管日程 / 比价购物 / 工作调研 / 其他
4. 下面哪些权限你**愿意**给它？（多选）读日历 / 读邮件 / 代发消息 / 代付款（有上限） / 都不愿意
5. 你最担心的是？ 隐私泄露 / 办错事 / 乱花钱 / 不知道它在干什么 / 价格太贵
6. 你能接受的月费？ 只用免费 / 20 元以内 / 20–100 元 / 100 元以上
7. 你希望 AI 代理人在什么时候必须先问你？（开放题）
8. 下一期想看我拆解什么？（开放题）
